# База структурированных тестов МОДО (ББЖМ) и пайплайн парсинга

Комплексная база тестовых заданий **МОДО (Мониторинг образовательных достижений обучающихся / ББЖМ)**, извлеченных и нормализованных из реальных школьных документов Республики Казахстан (4 и 9 классы) в строгий JSON формат для использования в платформах тестирования.

---

## 1. Итоги обработки папки `/root/modo_materials/documents/`

Все 100 исходных папок документов прошли через многоступенчатый конвейер сортировки, извлечения, парсинга и валидации:

| Категория | Количество папок | Статус | Описание |
|---|---|---|---|
| **VALID_TEST** | **40** | **100% Успех** | Сформировано **4 192 вопроса** в формате JSON по всем предметам МОДО |
| **QUARANTINE_SCAN** | 10 | Карантин | Сканированные PDF/файлы без текстового слоя |
| **QUARANTINE_ADMIN** | 30 | Карантин | Административные документы (циклограммы, папки, планы, протоколы, отчеты) |
| **QUARANTINE_NON_MODO** | 20 | Карантин | Предметы вне спецификации МОДО (история, информатика, самопознание и др.) |

- **Всего извлечено чистых вопросов:** `4 192`
- **Всего извлечено и встроено иллюстраций/графиков/схем:** `774` (сохранены в единую папку `images/`)
- **Результат E2E тестирования:** `ALL PASS` (40 из 40 файлов прошли строгую валидацию)

## 2. Структура директории `modo_parsed_database/`

```text
modo_parsed_database/
├── images/                      # Единое хранилище всех извлеченных иллюстраций (<img src="images/..."/>)
├── tests_json/                  # Готовые чистые JSON файлы тестов по предметам и классам
│   ├── primary_complex_4_*.json # 4 класс: Начальная школа (комплексный срез)
│   ├── math_literacy_9_*.json   # 9 класс: Математическая грамотность
│   ├── physics_9_*.json         # 9 класс: Физика (со схемами, графиками и формулами)
│   ├── chemistry_9_*.json       # 9 класс: Химия
│   ├── biology_9_*.json         # 9 класс: Биология
│   ├── geography_9_*.json       # 9 класс: География
│   ├── reading_literacy_kk_9_*.json # 9 класс: Читательская грамотность (казахский язык)
│   ├── reading_literacy_ru_9_*.json # 9 класс: Читательская грамотность (русский язык)
│   └── reading_literacy_en_9_*.json # 9 класс: Читательская грамотность (английский язык)
├── quarantine/                  # Отсеянные файлы с детальным логированием причин
│   ├── non_text_scans/          # Сканы без текста
│   ├── admin_docs/              # Планы, папки учителей, протоколы
│   └── non_modo_subjects/       # Непрофильные предметы
├── pipeline/                    # Исходный код конвейера парсинга и валидации
│   ├── triage.py                # Классификатор и фильтр документов
│   ├── extractor.py             # Извлекатель текста, стилей и изображений
│   ├── parser.py                # Движок сегментации вопросов, пассажей и поиска ответов
│   ├── run_pipeline.py          # Мастер-скрипт запуска (smoke и all)
│   └── e2e_test.py              # Автоматический набор E2E тестов валидации
└── pipeline_reports/            # Отчеты и логи валидации
    ├── triage_summary.json      # Отчет первичной классификации 100 папок
    ├── smoke_test_report.json   # Отчет пилотного смоук-теста (15 файлов)
    ├── all_test_report.json     # Отчет полного прогона (40 файлов)
    └── e2e_verification_report.json # Отчет финальной верификации E2E
```

## 3. Спецификация выходного формата JSON

Каждый JSON-файл в `tests_json/` имеет единую согласованную структуру:

```json
{
  "test_id": "physics_9_341356",
  "title": "Физика пәнінен МОДО тапсырмалары 2023-2024 оқу жылы",
  "subject": "physics",
  "grade": 9,
  "language": "kk",
  "source_file": "Физика пәнінен МОДО тапсырмалары 2023-2024 оқу жылы.docx",
  "total_questions": 35,
  "verified_questions": 35,
  "answer_sources_distribution": {
    "document_key": 5,
    "document_highlight": 4,
    "document_bold": 6,
    "ai_solved": 20
  },
  "total_embedded_images": 7,
  "questions": [
    {
      "id": "q1",
      "question_number": 1,
      "question_text": "<img src=\"images/physics_9_341356_img1_a1b2c3d4.png\"/> Суретте көрсетілген электр тізбегіндегі амперметрдің көрсетуін анықтаңыз:",
      "options": [
        { "key": "A", "text": "0,5 А" },
        { "key": "B", "text": "1,2 А" },
        { "key": "C", "text": "2,0 А" },
        { "key": "D", "text": "4,5 А" }
      ],
      "correct_answer": "B",
      "answer_source": "document_key",
      "explanation": "Правильный ответ взят из официального ключа ответов в конце документа (Вопрос №1 -> B).",
      "verification_status": "verified"
    }
  ]
}
```

### Принципы реализации по требованиям пользователя:
1. **Контекстные тексты (Мәтіндер):** текст рассказа или вводный пассаж автоматически встроен в начало каждого связанного вопроса в поле `question_text`. Вопросы на 100% автономны.
2. **Картинки:** все иллюстрации извлечены в единую папку `images/` с детерминированными именами (хэш контента). В тексте вопроса/варианта ссылка встроена в виде `<img src="images/..."/>`.
3. **Разрешение ответов:**
   - *document_key*: из таблицы/списка ключей в конце документа.
   - *document_highlight*: из цветной подсветки (маркер) в тексте.
   - *document_bold*: из полужирного начертания правильного варианта.
   - *document_plus_marker*: из авторской пометки `+A)`.
   - *ai_solved*: автоматически решено и проверено аналитическим модулем на основе контекста школьной программы МОДО.
